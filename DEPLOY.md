# Деплой сайта курса

Сайт — статика (HTML + CSS + SVG + шрифты), без бэкенда. Папка `site/` — это уже готовый корень сайта, собирать ничего не нужно.

## ✅ Сайт задеплоен на GitHub Pages

- **Живой адрес:** https://tuptop.github.io/dopechatka/
- **Репозиторий:** https://github.com/tuptop/dopechatka (публичный)
- **Как обновить сайт:** закоммитить изменения в `main` и запушить — GitHub Actions (`.github/workflows/pages.yml`) сам выложит содержимое `site/`:
  ```bash
  git add -A && git commit -m "Обновление" && git push
  ```
- **Свой домен:** в настройках репозитория → Pages → Custom domain, у регистратора CNAME-запись `www` → `tuptop.github.io` (и A-записи apex на IP GitHub Pages).

## 💳 Оплата через Продамус — как включить

Сайт статический (без бэкенда), поэтому оплата работает через готовую платёжную
страницу Продамуса: кнопка «Оформить предзаказ» редиректит на неё, после оплаты
Продамус возвращает покупателя на нашу страницу «спасибо».

Всё уже подготовлено, осталось **одно действие** — вписать поддомен payform.

1. Зарегистрироваться в Продамусе, создать платёжную форму, получить адрес вида
   `https://ВАШПОДДОМЕН.payform.ru`.
2. В `site/index.html` найти блок `ОПЛАТА (Продамус)` (в начале `<script>`) и заполнить:
   ```js
   const PAY = {
     shop: 'ВАШПОДДОМЕН',   // ← например 'dopechatka'  (без .payform.ru)
     price: '4500',         // цена предзаказа в рублях
     product: 'Курс по допечатке — предзаказ',
     fallback: 'https://t.me/tuptoppppp'
   };
   ```
   Как только `shop` заполнен — обе кнопки «Оформить предзаказ» ведут на оплату
   (в той же вкладке). Пока пусто — ведут в Телеграм (запасной вариант).
3. Запушить изменения (см. «Как обновить сайт»).

**Что уже сделано в коде:**
- Обе кнопки помечены классом `js-checkout` и берут ссылку из одной точки (`PAY`).
- Ссылка на оплату собирается с параметрами Продамуса: `do=pay`, товар, цена,
  `urlSuccess` → `success.html`, `urlReturn` → `fail.html`.
- Страницы после оплаты: [`success.html`](site/success.html) («Спасибо, оплата прошла»)
  и [`fail.html`](site/fail.html) («Оплата не прошла») — в стиле сайта.

**Настроить в кабинете Продамуса:**
- Товар/цену (можно оставить из URL-параметров или задать в форме).
- Кассу/чек (54-ФЗ): самозанятым — привязать «Мой налог», ИП — свою онлайн-кассу
  или облачную кассу Продамуса.
- Проверить, что после оплаты покупатель попадает на `…/dopechatka/success.html`.

**Проверка перед боем:** сделать тестовую оплату (в Продамусе есть тест-режим),
убедиться, что редирект на `success.html` срабатывает и приходит чек.

## Вариант А (рекомендую): свой VPS + nginx

Подходит, если уже есть сервер. Если нет — самый дешёвый VPS (Timeweb, Beget, reg.ru) за ~200–300 ₽/мес.

1. Направить домен на сервер: A-запись `@` и `www` → IP сервера.
2. На сервере:
   ```bash
   sudo apt update && sudo apt install -y nginx certbot python3-certbot-nginx
   sudo mkdir -p /var/www/dopechatka
   ```
3. Конфиг `/etc/nginx/sites-available/dopechatka`:
   ```nginx
   server {
     server_name example.ru www.example.ru;   # ← домен
     root /var/www/dopechatka;
     index index.html;
     gzip on;
     gzip_types text/css application/javascript image/svg+xml;
     location ~* \.(svg|ttf|otf|woff2?)$ { expires 30d; add_header Cache-Control "public"; }
   }
   ```
   ```bash
   sudo ln -s /etc/nginx/sites-available/dopechatka /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   sudo certbot --nginx -d example.ru -d www.example.ru   # HTTPS
   ```
4. Выкладка с мака (и каждое обновление) — одна команда:
   ```bash
   rsync -avz --delete "~/Yandex.Disk.localized/Совместная работа/Мой курс по допечатке/site/" user@server:/var/www/dopechatka/
   ```

## Вариант Б (без сервера вообще): статичный хостинг

- **GitHub Pages** — бесплатно: репозиторий, в Settings → Pages указать папку, свой домен подключается CNAME-записью.
- **Netlify / Vercel** — бесплатно, деплой перетаскиванием папки `site/` в браузер. Иногда медленные из РФ.
- **Beget / Timeweb «хостинг сайтов»** — залить содержимое `site/` по FTP/SFTP в `public_html`.

## После выкладки

- Подключить Яндекс.Метрику (вебвизор покажет, докуда долистывают и жмут ли на предзаказ).
- Проверить страницу в Телеграм-превью и ВК (og-теги).
- Конвертировать шрифты в woff2 (сейчас ttf/otf, woff2 в ~2 раза легче): `pip install fonttools brotli && fonttools ttLib.woff2 compress <файл>`.
- Прогнать Lighthouse в Chrome DevTools.

## Что сознательно отложено

- Мобильная вёрстка: сейчас страница пропорционально масштабируется под ширину экрана (JS в `index.html`). Для отдельной мобильной раскладки нужен мобильный макет.
- ~~Аккордеон «Вопросы»~~ — свёрстан: рабочий аккордеон в два столбца (`<details>`). Тексты вопросов можно править прямо в `index.html`.
