# Первые задачи по проекту

Хорошие задачи, чтобы въехать в проект на реальных мелочах. Отсортированы от простого к
чуть сложнее. Перед вёрсткой прочитай [CLAUDE.md](CLAUDE.md) (раздел «Работа с холстом»).

### 1. Фавиконка (иконка во вкладке) — просто, заметный результат
Сейчас её нет. Сделать из логотипа-кляксы (`site/assets/logo.svg`): положить `favicon.svg`
(и `favicon.png` 32×32 как запасной) в `site/assets/` и подключить в `<head>` `index.html`:
```html
<link rel="icon" href="assets/favicon.svg" type="image/svg+xml">
<link rel="icon" href="assets/favicon.png" sizes="32x32">
```
Проверить во вкладке и в Телеграм-превью. Вёрстку страницы не затрагивает.

### 2. Alt-тексты у картинок — просто, польза для SEO и доступности
Пройтись по `<img>` в `index.html` и `urok/index.html`: у смысловых картинок дать осмысленный
`alt`, у чисто декоративных оставить `alt=""`. Ничего не двигает, только атрибуты.

### 3. Шрифты в woff2 — средне, ускоряет загрузку
Сейчас шрифты `.otf` (`site/fonts/`), тяжёлые. Сконвертировать в woff2 (в ~2 раза легче):
```bash
pip install fonttools brotli
fonttools ttLib.woff2 compress site/fonts/TTNorms-Regular.otf   # и остальные
```
В `style.css` в `@font-face` добавить woff2 первым в `src` с fallback на otf. Проверить, что
шрифт грузится (Network) и текст не «прыгает». Не забыть поднять `?v=` у style.css.

### 4. Яндекс.Метрика — просто (нужен номер счётчика от Паши)
Когда будет ID счётчика — вставить стандартный сниппет Метрики в `<head>`. Вебвизор покажет,
докуда долистывают и жмут ли «Оформить предзаказ». Требует данные от владельца.

### 5. Вычитать черновые ответы в FAQ — просто (согласовать с Пашей)
В секции «Вопросы» два ответа помечены как выведенные из контекста, а не подтверждённые:
«На каких программах это работает?» и «Как оформить предзаказ?». Свериться с реальностью и
поправить формулировки.

### Не бери пока (нужны решения владельца)
- Перекройка первого экрана / позиционирования (три роли vs две) — решено оставить как есть.
- Мобильная раскладка — отложена сознательно (нужен отдельный мобильный макет).
- Включение реальной оплаты Продамус — по готовности кабинета (см. DEPLOY.md).
